# 🔍 Animated Expanding Search Bar

CSS va HTML yordamida yaratilgan zamonaviy, animatsiyali va interaktiv qidiruv paneli proekti.

## ✨ Xususiyatlari

* 🎯 **Smooth Slide Animation:** Sichqoncha ustiga borishi (`:hover`) bilan chapdan o'ngga qarab silliq kengayadi.
* 🎨 **Gradient Border:** Atrofida ko'zga tashlanadigan chiroyli gradient chegara.
* ✍️ **Dynamic Color Change:** Inputga matn yozilishi bilanoq gradient rangi va yog'dusi avtomatik o'zgaradi (`:has()` va `:not(:placeholder-shown)` orqali).
* 📱 **Minimal & Responsive:** Toza va zamonaviy UI dizayn.

## 🛠 Ishlatilingan texnologiyalar

* **HTML5**
* **CSS3** (Flexbox, CSS Animations, Pseudoclasses)
* **Font Awesome v6** (Ikonkalar uchun)
